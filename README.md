# 🌱 Habit Garden

Habit Garden is a habit and skill-building application that turns consistent practice into a growing virtual garden.

Instead of simply tracking numbers, Habit Garden gives each skill its own plant. As you spend real time practicing, your plant grows through different stages.

## ✨ Features

- 🌱 Create multiple skills and habits
- 🌿 Individual plant for each skill
- ⏱️ Practice timer for recording real practice time
- 📈 Plant growth based on completed practice time
- 🔥 Daily streak tracking
- 📊 Progress dashboard and weekly statistics
- 🗓️ Journey duration and daily practice goals
- 🌳 Garden view containing all your plants
- 🔐 User authentication
- 📧 Welcome email
- 🔑 Forgot password and password reset
- 👁️ Show/hide password
- 📱 Responsive interface
- 🌿 Garden-themed UI
